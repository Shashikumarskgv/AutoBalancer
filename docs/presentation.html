08 / SYSTEM STABILITY

THE 6 PRODUCTION GUARDRAILS

🛡️ GUARDRAIL 1: BOUNDARY CLAMP

Strictly confines difficulty between Level 1 and Level 5. Level 5 cannot increase; Level 1 cannot decrease.

1 ≤ difficulty ≤ 5
⚡ GUARDRAIL 2: MAX STEP LIMIT

Restricts adjustments to maximum ±1 level per change. Prevents abrupt jarring jumps like 2 → 5.

MAX_DIFFICULTY_STEP = 1
⏱️ GUARDRAIL 3: COOLDOWN WINDOW

Enforces a 30-second refractory cooldown period between adjustments to allow player stabilization.

DIFFICULTY_COOLDOWN_SECONDS = 30
📊 GUARDRAIL 4: MINIMUM SAMPLES

Requires at least 10 recorded gameplay actions before evaluating any dynamic adjustment.

MIN_ACTIONS_FOR_ADJUSTMENT = 10
🔄 GUARDRAIL 5: HYSTERESIS BUFFER

Suppresses immediate oscillating demotions (3 → 4 → 3) unless performance degradation exceeds 15%.

HYSTERESIS_THRESHOLD = 0.15
🎯 GUARDRAIL 6: CONFIDENCE FILTER

Rejects model predictions with probability below 65% (CONFIDENCE_THRESHOLD = 0.65).

Explicit Reason: LOW_CONFIDENCE
Unit tested across 7 Jest scenarios in difficulty_guardrails.test.ts with 100% pass rate.
09 / REAL-TIME SYNCHRONIZATION

WEBSOCKET ARCHITECTURE: ZERO REFRESH

SUB-50MS EVENT PROPAGATION FLOW SOCKET.IO ROOMS
1
Event Ingestion: Player hits or misses target; client posts event payload to Express /api/game/event.
2
ML Inference & Guardrail Audit: API builds 14-feature vector, queries FastAPI /predict, and validates 6 guardrails.
3
Targeted WebSocket Broadcast: Socket.IO emits event DIFFICULTY_UPDATED to authenticated room player:<playerId>.
4
Immediate Canvas Adaptation: Game HUD displays promotion modal; target speeds & spawn timers adjust smoothly without reload.
⚡

ZERO PAGE REFRESH

Traditional web games interrupt gameplay with page reloads or loading spinners. This system delivers seamless in-game level transitions.

Key Advantages:
• Unbroken player flow channel
• Zero state or score reset
• Sub-50ms sync latency
• Secure isolated player rooms
Guarantees that difficulty transitions support rather than disrupt the psychological flow state.
